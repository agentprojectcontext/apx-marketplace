# WordPress.com

Posts, pages and stats of your sites.

## Connection

Sign in through the service's browser authorization flow when APX starts its MCP server. For a self-hosted WordPress site connected through Jetpack, use the same WordPress.com account the site is linked to. Check [Jetpack setup](https://jetpack.com/support/create-better-content-with-jetpack-ai/mcp/) and the [current WordPress.com availability](https://developer.wordpress.com/docs/mcp/) before connecting; availability can depend on your site and plan. Review each site's read and write access. A connection may see more than one site linked to your account. This is not the standalone WordPress MCP Adapter.

The package preserves the native catalog's exact MCP executable, arguments, environment and endpoint. It neither replaces the upstream server nor narrows its tool set or account permissions. Review the actual upstream tools and granted permissions before enabling it.

## Verification

Structural tests compare the packaged connection to the native catalog definition. The package is also checked by the actual APX consumer; an inspect/install-off check does not prove a live account journey. Account authorization, upstream service availability and real account operations have not been exercised for this package.

The rich listing, icon and any screenshot provenance are checked separately. Fictional APX-styled conversations are illustrations, not evidence of a live connection. The owner permits an empty screenshot array until suitable imagery is ready; no missing asset may be referenced.

## Español

Publicaciones, páginas y estadísticas de tus sitios.

Iniciá sesión en el navegador cuando APX arranque el servidor MCP. Si tu sitio WordPress está alojado por tu cuenta y conectado con Jetpack, usá la misma cuenta de WordPress.com a la que lo vinculaste. Revisá la [configuración de Jetpack](https://jetpack.com/support/create-better-content-with-jetpack-ai/mcp/) y la [disponibilidad vigente en WordPress.com](https://developer.wordpress.com/docs/mcp/): puede depender del sitio y del plan. Revisá los permisos de lectura y escritura de cada sitio. Una conexión puede acceder a más de un sitio vinculado a la cuenta. Esta ficha no instala WordPress MCP Adapter.

La extensión conserva el ejecutable MCP, sus argumentos, el entorno y la dirección del catálogo nativo. No reemplaza el servidor ni reduce sus herramientas o permisos. Revisá las herramientas reales y los permisos concedidos antes de activar.

Las pruebas estructurales comparan la conexión empaquetada con el catálogo nativo y el consumidor real de APX comprueba el paquete. Inspeccionar o instalar apagado no prueba una cuenta real: no se verificaron la autorización, la disponibilidad externa ni las operaciones sobre cuentas para este paquete.

La ficha, el ícono y la procedencia de imágenes se verifican por separado. Un chat ficticio con estilo APX es una ilustración, no prueba de conexión. Se permite dejar capturas vacías hasta tener una buena imagen, pero nunca referenciar un archivo que falta.
